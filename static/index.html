Instagram

Steps to get the Instagram token with the unified login (one time, 15 minutes)
  1. In the Instagram app, open Settings → Account type and tools → Switch to professional account. Select Creator.
  2. Open developers.facebook.com/apps and open your app. A business portfolio must own the app, and the app must have the use case Manage messaging & content on Instagram.
  3. Open Use cases → Manage messaging & content on Instagram → Customize → API setup with Unified login.
  4. Open Configure your app and select Create new configuration. In the preview, select Edit permissions. Keep instagram_basic and instagram_content_publish, and add instagram_manage_insights. If the page lets you select the life of the token, select the token that does not expire.
  5. Select Use this configuration. If the page asks for a redirect URL, enter https://arorashivoy.win/cutting-room/ and select Save.
  6. Open Generate access tokens. Select Add account and invite your Instagram account as an Instagram Tester.
  7. In Instagram on the web, open Settings → Website permissions → Apps and websites → Tester invites and accept the invite.
  8. Go back to the Meta app and select Generate token next to the account. Complete the login. Copy the token. Meta shows it one time only.
  9. Paste the token below and select Save and test. The token starts with EAA.

The app stays in Development mode. That is sufficient for your own account. This way needs no Facebook Page.

Other token types that the dashboard accepts
  • Instagram login (older Meta apps): a token that starts with IGAA. The dashboard renews it each week.
  • Facebook login: a user token that starts with EAA, from the Graph API Explorer. The Instagram account must be linked to a Facebook Page. Save the Meta app ID and the app secret below first, so the dashboard can change the token into one that lasts 60 days.

YouTube

Steps to connect YouTube (one time, 15 minutes)
  1. Open console.cloud.google.com and create a project.
  2. In APIs & Services → Library, enable YouTube Data API v3 and YouTube Analytics API.
  3. In Google Auth Platform → Branding, fill in the app name and your email. In Audience, select External, then select Publish app. A token of an app in Testing status stops after 7 days.
  4. In Clients, create a client of the type Desktop app. Copy the client ID and the client secret into the fields below. Select Save.
  5. Select Connect YouTube. Log in. Google shows a warning for an unverified app. Select Advanced → Go to the app and accept.
  6. The browser then opens an address that starts with . If the page does not load, copy the full address from the address bar and paste it below.
YouTube locks each video from a new API project to private. After the upload, set the video to public in YouTube Studio. To remove the lock, request the API audit from Google.
